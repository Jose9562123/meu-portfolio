## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu **Portfólio Web Pessoal e Profissional**. O projeto foi desenhado com uma estética **Cyber/Tech**, moderna, totalmente responsiva para dispositivos móveis, e estruturado para apresentar minha formação, competências técnicas e serviços prestados em Análise de Sistemas e Tecnologia da Informação.

---

## ⚡ Principais Funcionalidades

- 📱 **Interface 100% Responsiva:** Otimizada dinamicamente para smartphones, tablets, notebooks e telas widescreen.
- 🎨 **Design Tech/Cyber Analyst:** Paleta de cores moderna focada em legibilidade e experiência do usuário (UX).
- 🍔 **Navegação Fluida:** Header fixo com menu animado para mobile e rolagens suaves.
- 📊 **Currículo Interativo:** Seção no formato dashboard destacando formação acadêmica, especializações e stack técnica.
- 📩 **Formulário de Contato:** Validação no front-end com notificações personalizadas estilo *Toast*.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5 semântico, CSS3 (Flexbox, CSS Grid, variáveis CSS e Media Queries), JavaScript Vanilla (ES6+).
- **Tipografia & Ícones:** Google Fonts (*Inter*), vetores SVG integrados nativamente.
- **Ambiente & Ferramentas:** Git/GitHub, Linux (Ubuntu/Kali Linux), VS Code.

## 🚀 Como Executar o Projeto Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/meu-portfolio.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd meu-portfolio
   ```

3. Abra o arquivo `index.html` em seu navegador de preferência ou utilize a extensão **Live Server** no VS Code.
